Welkom

Ondanks dat ik deze omgeving niet actief promoot, ben je hier als lezer meer dan welkom. Via deze omgeving verzamel ik zoveel mogelijk kennis over mijn eigen vakgebied: Enterprise Architectuur.

De afgelopen 25 jaar ben ik regelmatig teruggevallen op diverse soorten raamwerken, best practices en methodes. Het lijkt mij daarom leuk en nuttig om daar maatwerk versies van uit te werken in deze omgeving. Het geeft mij een toegankelijke gereedschapskist waarin ik snel iets kan opzoeken om in te zetten als gereedschap.

Realiseer je als lezer dat het meeste wat je hier leest bewust op maat gemaakt is voor mijn eigen manier van denken en werken, en dus in meer of mindere mate kan afwijken van het origineel. Vaak is dat een bewuste keuze, maar ik realiseer mij ook dat ik dingen verkeerd kan interpreteren. Prima als je mij daar als lezer op aanspreekt.

OPMERKING - Op dit moment is dit nog een lege omgeving. Ik geef nu vooral prioriteit aan mijn repository architectuur-zorg

Marcel Schrauwen
