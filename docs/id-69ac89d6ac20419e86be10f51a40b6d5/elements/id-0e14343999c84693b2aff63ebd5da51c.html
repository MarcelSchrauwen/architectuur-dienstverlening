Licentie en hergebruik ()

Ik heb deze architectuurrepository opgezet als een persoonlijke gereedschapskist voor mijn dagelijkse werkzaamheden op het gebied van enterprise-architectuur, informatievoorziening en digitale zorg. Hierin verzamel ik kennis, modellen, inzichten, referenties en architectuurartefacten die ik gebruik in mijn werk.

Omdat ik graag mijn kennis deel met anderen, stel ik deze repository openbaar beschikbaar. De inhoud mag vrij worden geraadpleegd, gebruikt en aangepast voor niet-commerciële doeleinden, mits de bron wordt vermeld.

Commercieel hergebruik van de inhoud, geheel of gedeeltelijk, is niet toegestaan zonder mijn voorafgaande toestemming. Ik behoud mij het recht voor om individuele personen of organisaties expliciet toestemming te verlenen voor commercieel gebruik van (delen van) deze repository.

Deze repository is een levend geheel dat voortdurend wordt aangevuld en verbeterd. Hoewel ik streef naar een zo hoog mogelijke kwaliteit en actualiteit, kunnen aan de inhoud geen rechten worden ontleend.

Tenzij anders vermeld, wordt de inhoud beschikbaar gesteld onder de licentie Creative Commons Naamsvermelding-NietCommercieel-GelijkDelen 4.0 (CC BY-NC-SA 4.0).).

Wat voor mij een praktische gereedschapskist is, hoop ik ook voor anderen een bruikbare bron van kennis en inspiratie binnen de zorg te laten zijn.
